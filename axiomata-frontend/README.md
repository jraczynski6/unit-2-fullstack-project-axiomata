# Axiomata

A full-stack world-building application.

## Project Structure

```
axiomata-backend   # Spring Boot API
axiomata-frontend  # React (Vite) client
```

## Backend

- Java
- Spring Boot
- REST API
- JWT Authentication (planned)

Run from the backend folder:

```
./mvnw spring-boot:run
```

or

```
mvn spring-boot:run
```

## Frontend

- React (Vite)
- Axios
- Context API (planned)

Run from the frontend folder:

```
npm install
npm run dev
```

## Status

MVP in active development.
